# 🌱 Java Fundamentals to OOPs

Hi 👋 I'm Gayathiri!  
I started this **Java Learning Repo** for beginners who want to learn **Java from scratch** — covering everything from **Data Types to OOP Concepts** in just **2 weeks** 

This repo includes:
- 🧩 Daily Java practice programs by day wise 
- 🧠 Step-by-step topics from basics to OOPs Concept 
- 🕹️ Simple console-based projects for hands-on learning  

---

## 📅 Learning Plan (2 Weeks)

### **Week 1: Java Basics**
Focus: Syntax, Variables, Data Types, Loops, Conditional Statements, Arrays, and Methods.

**Mini Projects:**
- 🎮 Tic Tac Toe Game (using loops & conditions)  
- 🧮 Calculator (using `switch` case)

---

### **Week 2: OOP Concepts**
Focus: Classes, Objects, Constructors, Inheritance, Polymorphism, Encapsulation, and Abstraction.

**Mini Project:**
- 🧠 Memory Game (Object-Oriented Project)
